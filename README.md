# Rocket ToDo

Aplicação web simples para organizar tarefas. Permite criar tarefas, marcá-las como concluídas e removê-las. Os dados ficam salvos no armazenamento local do navegador.

<br />

## Funcionalidades

- Criar tarefas
- Marcar e desmarcar tarefas como concluídas
- Remover tarefas
- Acompanhar a quantidade de tarefas criadas e concluídas
- Manter as tarefas salvas no navegador

<br />

## Tecnologias

- HTML
- CSS
- JavaScript Vanilla
